# Code review

## Правила PR

- Pull request має бути до 400 змінених рядків: великі зміни ділимо на кілька PR.
- Назва PR - у форматі Conventional Commits, наприклад feat: add export to CSV.
- Злити PR можна після щонайменше одного approve і зеленого CI.

## Для рецензента

Перше ревʼю - протягом одного робочого дня. Коментарі з префіксом nit: - це побажання, автор може їх не виправляти. Блокуйте PR лише через баги, безпеку чи порушення архітектури.
