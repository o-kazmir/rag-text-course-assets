# Деплой

## Регулярні релізи

Production-деплой відбувається у вівторок і четвер о 14:00. За дві години до релізу, о 12:00, починається code freeze: у гілку main потрапляють лише виправлення для поточного релізу.

## Заборони

У пʼятницю, вихідні та державні свята деплоїти в production заборонено.

## Хотфікси

Критичне виправлення можна викотити будь-коли за погодженням чергового інженера. Хотфікс обовʼязково проходить code review і всі перевірки CI.

## Відкат

Якщо після релізу зростає кількість помилок, черговий запускає make rollback - це повертає попередню версію за 5 хвилин.
