# Онбординг

## День 1

Ви отримуєте доступи до Google Workspace, Slack, GitHub і Linear. Тімлід знайомить вас з командою і призначає бадді - колегу, якому можна ставити будь-які питання в перші три місяці.

## Дні 2-3

Налаштуйте локальне середовище за README репозиторію platform. Якщо щось не запускається, це баг документації: виправте README своїм першим PR.

## До кінця тижня

Візьміть задачу з міткою good-first-issue в Linear і доведіть її до production. У пʼятницю о 16:00 коротко покажіть результат на командному демо.

## Випробувальний термін

Триває 3 місяці. Наприкінці кожного місяця - зустріч один на один з тімлідом.
